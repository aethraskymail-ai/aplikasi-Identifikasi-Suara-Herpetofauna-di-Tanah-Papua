Suara Katak Papua

Identifikasi suara herpetofauna dari rekaman AudioMoth (PAR)

Unggah rekaman (WAV/FLAC/MP3/M4A, boleh banyak sekaligus). Nama asli AudioMoth YYYYMMDD_HHMMSS.WAV dibaca untuk cek jendela 17:30–21:00. Gunakan Pilih folder untuk membaca lokasi PARxxx dari nama folder; file bukan audio akan dilewati.

Rekaman

    Pilih atau unggah rekaman.

    Model kustom (Perch embedding + regresi logistik)

    Beri label per jendela 5 detik di tab Analisis (nama jenis, atau bukan katak), lalu latih. Model baru dipakai di semua rekaman.

    Unduh label (CSV)

    Jumlah label per kelas

    Cara kerja

    1. Penyaringan tervalidasi: highpass 2.100 Hz ×2, lowpass 8.000 Hz ×2, deteksi puncak nada sempit via FFT rata-rata per file di luar pita katak 2,4–3,8 kHz, notch bertingkat (−40..−50 dB, 3 lebar), normalisasi puncak ke −2 dBFS, keluaran 48 kHz PCM 16-bit. Tidak memakai afftdn/anlmdn, spectral subtraction, bandreject statis atau loudnorm.
    2. Deteksi aktivitas di pita katak: bagian yang ≥6 dB di atas lantai derau.
    3. Google Perch v2 mengubah tiap jendela 5 detik menjadi embedding 1.536 angka. Perch juga punya ±1.350 label amfibi, tetapi hampir semuanya jenis Amerika/Australia/Afrika: tebakan langsungnya hanya pembanding, bukan identifikasi jenis Papua.
    4. Model kustom belajar dari label Anda sendiri pada embedding Perch. Inilah jalur identifikasi jenis Papua. Mulailah dengan beberapa jenis yang sudah yakin (diverifikasi ahli) plus kelas bukan katak.

    Untuk 102.734 file di hardisk

    Jalankan skrip batch di komputer yang tersambung ke hardisk (lihat README): python -m suarakatak.batch --masukan I:\PAR --keluaran I:\HASIL_EKSTRAKSI\HASIL. Skrip memilih jam 17:30–21:00 dari nama file, menyaring, dan menulis CSV ringkasan + embedding Perch.

    Rekaman contoh sintetis hanya meniru profil gangguan PAR001 (dengung, serangga 2.063 Hz, jangkrik) dan pulsa ~2.940 Hz; itu bukan suara katak asli.
